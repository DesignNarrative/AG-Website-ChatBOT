AI-powered property sales chatbot for Abhinav Group.

== Description ==

This plugin loads the Abhinav Group AI property sales chatbot on your WordPress website.

Features:
* Floating chat widget (bottom-right, configurable)
* English and Hindi language support
* Property enquiry, pricing, brochure, and lead capture
* Connects to the Abhinav Group chatbot API backend
* Does NOT modify any existing site functionality
* Does NOT interfere with the existing WhatsApp integration
* Safe to deactivate at any time

== Installation ==

1. Upload the `abhinav-chatbot-plugin` folder to `/wp-content/plugins/`
2. Activate the plugin via the WordPress admin
3. Go to Settings → Abhinav Chatbot
4. Enter the API Base URL (provided by your developer)
5. Optionally enter the Widget API Key
6. Enable the chatbot and save

== Frequently Asked Questions ==

= Will this break my existing website? =
No. The plugin only adds a floating chat widget. All other functionality is unchanged.

= Does this affect the existing WhatsApp integration? =
No. This plugin has no connection to any WhatsApp system.

= How do I remove the chatbot? =
Deactivate and delete the plugin. No database cleanup is required beyond the plugin settings option.
